# Flicks platform demos

Clickable concepts of Flicks inside partner platforms, one folder per platform, served on GitHub Pages.

| Demo | Link |
|---|---|
| noon (UAE, English) | https://flamdesign.github.io/flicks-platform-demo/noon/ |

`kit/` holds the shared Flicks Demo Kit (`kit.js`, pasted unchanged into every demo) and the device test harness (`qa.py`). Test any demo with `python3 kit/qa.py <url> --live`.

Built by Flam for partner conversations. Not affiliated with or endorsed by the platforms or brands shown.
